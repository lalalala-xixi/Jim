# 任务代办

一个纯前端的单文件待办清单页面。打开 `index.html` 即可使用，支持添加任务、设置截止时间、标记完成、按截止时间排序、过期提醒和导出 TXT。

页面不依赖任何框架、构建工具或外部资源，HTML、CSS 和 JavaScript 全部内联在 `index.html` 中。

## 功能

### 任务列表与完成状态

- 内置 5 条示例任务，其中 2 条为已完成状态。
- 点击任意未完成任务行即可标记为完成：文字变灰、加删除线，标签变为「已完成」，底部统计同步更新。
- 已完成任务再次点击不会取消完成；当前没有单条删除或改名功能。
- 「全部完成」把当前所有任务标记为完成，全部完成后按钮自动禁用；新增任务后会重新启用。
- 「清空」移除所有已完成任务，未完成任务保留；没有已完成任务时点击无变化。

### 添加任务与截止时间

- 在「添加任务」区域输入任务名称，选择日期时间，点击「保存」或按 Enter。
- 名称与现有任务一致（忽略大小写及多余空格）时，更新该任务的截止时间。
- 名称不存在时，新建一条「待开始」任务并设置截止时间，新任务会加入列表末尾。
- 名称为空提示「请输入任务名称」；时间为空提示「请先选择截止时间」。
- 日期时间默认是明天的 18:00。
- 任务名称在创建时确定，之后不能修改。

### 截止时间持久化

- 截止时间保存在浏览器 `localStorage` 的 `todo-deadlines` 键中，格式如：

  ```json
  { "t3": "2026-11-13T18:00" }
  ```

- 初始任务的 `data-id` 为 `t1`–`t5`；刷新后按 id 恢复对应截止时间。
- 浏览器禁用本地存储时，页面会提示「已更新显示，但浏览器阻止了本地保存」。
- 清除浏览器站点数据会同时清除已保存的截止时间。

### 排序

- 标题栏按钮「按截止时间 早→晚」/「按截止时间 晚→早」表示下一次点击的排序方向，点击后自动切换。
- 没有截止时间的任务始终排在最后。
- 所有任务都没有截止时间时，点击排序会提示先设置截止时间。
- 排序只影响显示顺序，不修改数据，刷新后恢复初始顺序。

### 过期提醒

- 未完成且超过截止时间的任务，截止时间显示为红色「已过期 · 截止 …」。
- 页面顶部出现「有 N 项任务已过期，请及时处理」的提醒条。
- 页面每 30 秒自动检查一次；已完成任务不计入过期提醒。

### 导出 TXT

- 点击标题栏「导出」下载 `任务清单-YYYY-MM-DD.txt`。
- 导出内容包括：标题、导出时间、当前顺序的任务列表（状态、任务名、截止时间、是否过期）和完成统计。
- 导出示例：

  ```text
  任务代办
  导出时间：2026-11-12 14:45

  1. [已完成] 整理本周的工作计划
  2. [已完成] 阅读 Git 基础教程
  3. [未完成] 练习提交与分支操作（截止 11月13日 18:00）
  4. [未完成] 编写项目说明文档
  5. [未完成] 回顾今天的学习笔记

  已完成 2 项 · 还剩 3 项
  ```

- 文件使用 UTF-8（带 BOM）和 CRLF 换行，用 Windows 记事本打开中文不会乱码。
- 导出的是当前页面上的任务，排序、清空、新增后的结果都会反映在文件里。

## 快速开始

无需安装依赖或启动服务器，直接用浏览器打开 `index.html`：

```
file:///F:/Git学习/index.html
```

也可以在文件管理器中双击 `index.html`。

## 数据与持久化范围

| 数据 | 是否持久化 | 说明 |
| --- | --- | --- |
| 截止时间 | 是 | 保存在 `localStorage` 的 `todo-deadlines` |
| 完成状态 | 否 | 刷新后恢复初始的 2 条已完成任务 |
| 清空操作 | 否 | 刷新后被清空的任务会重新出现 |
| 新增任务 | 否 | 刷新后只保留初始的 5 条任务 |
| 排序方向 | 否 | 刷新后回到初始顺序 |

刷新页面后，新增任务会消失，但它的截止时间仍可能留在 `localStorage` 中；由于对应任务已不存在，这些记录不会显示，也不影响页面使用。

## 已知限制

- 顶部「今天是 11 月 9 日」是静态示例文案，不会随系统日期变化。
- 没有单条删除、取消完成、任务改名功能。
- 「清空」和「全部完成」没有二次确认。
- 新任务、完成状态和清空结果都不跨刷新保留，只有截止时间会保留。
- 导出依赖浏览器的本地下载能力；若浏览器拦截下载，需要手动允许。

## 自定义

- **初始任务**：编辑 `index.html` 中 `<ul class="todo-list">` 里的 `<li>`，保持每个 `data-id` 唯一。已完成任务需要同时设置 `done` 类、`checked` 复选框和「已完成」标签。
- **样式**：全部写在 `<style>` 中，主色为 `#4f7cff`。
- **默认截止时间**：在脚本中搜索 `defaultDue`，修改「明天 18:00」的默认值。
- **存储键名**：修改脚本开头的 `STORAGE_KEY` 可更换截止时间的存储键。

## 实现说明

- 纯 HTML + CSS + JavaScript 单文件实现，没有第三方库。
- 脚本使用 IIFE 包裹，避免污染全局变量。
- 任务与截止时间通过 `data-id` 关联；任务数据本身不序列化，只保存截止时间。
- 导出使用 `Blob`、`URL.createObjectURL` 和临时 `<a download>` 触发下载。
- 适用于现代 Chrome、Edge、Firefox；不支持 IE。
