# 任务代办（静态页面）

一个最简单的静态「任务代办」界面，用于展示待办清单的外观。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面本体，HTML + 内联 CSS，无外部依赖 |
| `README.md` | 本说明文件 |

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何环境或启动服务器。

也可以在文件管理器中双击 `index.html`，或在浏览器地址栏输入文件路径：

```
file:///F:/Git学习/index.html
```

## 说明

- 纯静态页面，不包含任何 JavaScript，复选框仅作展示、不可交互。
- 样式全部写在内联 `<style>` 中，不依赖外部字体、图片或 CSS 文件。
- 修改任务内容时，直接编辑 `index.html` 中 `<ul class="todo-list">` 里的 `<li>` 即可。
